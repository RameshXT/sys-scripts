Alt + 0

Alt + 7

Single Press: Antigravity IDE
Double Press: Open in active Explorer folder
Alt + C
Single Press: Google Chrome
Hold >600ms: Incognito Mode
Alt + E
Outlook (Auto-Maximize)
Alt + G
Single Press: Git Bash
Double Press: Open in active Explorer folder
Alt + I
Instagram (Auto-Maximize)
Alt + M
Microsoft Store
Alt + N
Notepad
Alt + O
Single Press: Command Prompt (CMD)
Double Press: Open in active Explorer folder / Admin CMD (if no folder active)
Hold >600ms: Admin CMD in Folder
Alt + P
Single Press: PowerShell
Double Press: Open in active Explorer folder / Admin PowerShell (if no folder active)
Hold >600ms: Admin PowerShell in Folder
Alt + Q
Single Press: Close Active Window
Hold: Continuous safe window close
Alt + S
Slack (Auto-Maximize)
Alt + T
Telegram
Alt + U

Single Press: VS Code
Double Press: Open in active Explorer folder

Alt + W
WhatsApp (Auto-Maximize)
Alt + Y
YouTube (Auto-Maximize)
Alt + Z
