Zero Config

One command installs AHK v2, downloads scripts, and wires it up.

🚀

Portable

100% isolated inside LocalAppData. Zero admin rights needed.

⚡

Built-in CLI

Manage, restart, and update natively from any PowerShell window.

CLI Commands

xtkeys status Check if the process is running
xtkeys update Pull latest scripts & restart
xtkeys restart Force kill and cleanly re-launch
xtkeys uninstall Safely remove everything
